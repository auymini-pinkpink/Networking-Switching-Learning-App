# Networks & Switching Learning App

An interactive web application designed to teach network fundamentals, subnetting, switching, VLANs, STP, and exam prep for cybersecurity students.

## Features
- **Subnetting & VLSM Calculators:** Instant IPv4 calculation & step-by-step guidance.
- **IP Fragmentation Visualiser:** Shows fragment payloads, offsets, and MF flags.
- **Interactive Simulators:** STP election, VLAN tagging, and TCP 3-way handshake.
- **Mock Exam Engine:** Practice under realistic topic weightings (90-mark standard).

## Quick Start
1. Clone the repository or download the source code.
2. Open `index.html` in any web browser.
